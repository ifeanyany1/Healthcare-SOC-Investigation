# Dataset

The original `Patient_Claims.csv` with **104 synthetic claims** was created in the Windows 11 lab at:

```text
C:\Healthcare-SOC-Lab\Patient_Claims.csv
```

**The original CSV was not in the uploaded screenshots ZIP.** To include it in the GitHub project, copy that original file from the VM into this folder and name it `Patient_Claims.csv`. Do not substitute real healthcare data or patient identifiers.

The [dataset validation screenshot](../Screenshots/07-Healthcare-Claims-Dataset.png) verifies the record count. The CSV is intentionally not fabricated from the screenshot because only 15 of the 104 rows are visible there.
